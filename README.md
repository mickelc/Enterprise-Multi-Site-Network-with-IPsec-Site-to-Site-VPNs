# Enterprise-Multi-Site-Network-with-IPsec-Site-to-Site-VPNs

A multi-site enterprise network designed, configured, and tested using Cisco Modeling Labs (CML). This project simulates an enterprise environment with a central headquarters, two remote branches, and an ISP network.

The lab demonstrates hands-on experience with Layer 2/Layer 3 switching, dynamic routing, firewall configuration, BGP, and IPsec site-to-site VPN connectivity.

---

## Network Topology

The network consists of three enterprise sites connected through a simulated ISP infrastructure:

- **Headquarters (HQ)** — Central enterprise site and IPsec VPN hub.
- **Branch 1 (BR1)** — Remote enterprise site connected to HQ.
- **Branch 2 (BR2)** — Second remote enterprise site connected to HQ.
- **ISP Router** — Simulates a service provider network and provides WAN connectivity between sites.

## Project Objectives

The primary objective was to design and implement a functional enterprise network capable of supporting segmented internal networks, dynamic routing, secure inter-site communication, and controlled traffic flow.

Key objectives included:

- Design a three-site enterprise network using Cisco CML.
- Configure VLANs and inter-VLAN routing.
- Implement Layer 3 connectivity between routers, firewalls, and switches.
- Configure OSPF for internal dynamic routing.
- Establish eBGP peering between enterprise routers and the ISP.
- Implement Cisco ASA firewall security policies.
- Configure IPsec site-to-site VPN tunnels using a hub-and-spoke topology.
- Troubleshoot routing, firewall, and VPN connectivity issues.
- Verify connectivity using Cisco IOS and ASA diagnostic commands.
